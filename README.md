# Portfólio — Théo Souza Santos

Site pessoal com meus projetos, formação e contato. Feito com Next.js, React,
Tailwind CSS e Motion, exportado como site estático e publicado no GitHub Pages.

## Rodando localmente

```bash
npm install
npm run dev
```

Abra http://localhost:3000.

## Publicação

Cada push na branch `main` gera o site (`npm run build` cria a pasta `out/`) e
publica no GitHub Pages pelo workflow em `.github/workflows/deploy.yml`.
